# ewvon

Plataforma de gestão corporativa: chat por setores, conversas diretas e grupos, chamadas, avisos, tarefas, calendário, aniversariantes, avaliações e Dash.

- Front-end: Vite + React + TypeScript + Tailwind/shadcn
- Back-end: Supabase (banco, autenticação, armazenamento e funções)
- Hospedagem: Vercel (https://ewvon.vercel.app)

## Desenvolvimento

```bash
npm install
npm run dev
```

Regras de arquitetura e decisões do projeto: veja `AGENTS.md`.
