# Demonstração isolada do Nuvexa

Esta pasta contém uma cópia dos arquivos-fonte do aplicativo na branch V5.0.0.1, preservando a estrutura original em demonstracao/src e os arquivos de configuração necessários como referência.

Importante: a cópia ainda contém integrações Supabase herdadas do código-fonte original. A persistência não foi convertida para localStorage nesta etapa; por isso, ela não deve ser tratada como demonstração offline nem executada como versão independente antes da adaptação do cliente de dados, autenticação, realtime e upload.
